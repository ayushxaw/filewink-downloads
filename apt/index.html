Filewink, a few commands away.

Quick file actions and editors, on your computer. Free to use, with no account or ads.

This beta supports Ubuntu 24.04 and 26.04 on 64-bit Intel/AMD computers.

Download the APT setup package, open a terminal in its folder, and run:

sudo apt install ./filewink-archive-keyring_2026.10.23.1_all.deb
sudo apt update
sudo apt install filewink

Open Filewink from Applications. For quick actions on a file, choose Open With → Filewink. Enable Files gestures in settings for Shift+hold in GNOME Files.

The setup package adds a public signing key and a source trusted only for Filewink. Future versions arrive through normal APT upgrades when published.
